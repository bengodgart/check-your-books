Publish guide, Check Your Books

How to run it locally and put it online for free. It is static files, so hosting is a drag-and-drop.

Serve it, do not double-click it. The page is ES modules, and browsers only load modules over http://, not from a file:// path. Run a tiny local server and open the http://localhost address. Double-clicking index.html will load a blank page.

Run it locally

Start a local server from the project folder. 
python -m http.server 8000
Run it from C:/dev/check-your-books, then open http://localhost:8000. Any static server works.
Confirm the kernel test passes. 
node test-node.mjs
Expect ALL PASS and exit code 0.
Click Load the sample messy export, then Audit. Try it with no key, then paste an Anthropic key in Settings for live mode.
The mode badge flips from DEMO (amber) to LIVE (green). The key stays only in your browser.

Deploy free, option A: Netlify drop

Go to app.netlify.com/drop.
No account is needed to start.
Drag the whole check-your-books folder onto the page.
Netlify gives you a live URL in a few seconds, served over https so the modules load.

Deploy free, option B: GitHub Pages

Create the public repo and push, run from C:/dev/check-your-books. 
gh repo create check-your-books --public --source . --push
Expect the repo URL printed.
Set the default branch to main. 
git branch -M main
git push -u origin main
Add discoverability topics. 
gh repo edit --add-topic ai,data-quality,bookkeeping,claude,csv,audit
Enable Pages from the main branch root. 
gh api -X POST repos/bengodgart/check-your-books/pages -f "source[branch]=main" -f "source[path]=/"
Then set the homepage: gh repo edit --homepage https://bengodgart.github.io/check-your-books/
Wait about a minute, then confirm the live page returns HTTP 200 and the tool loads from a fresh browser.
